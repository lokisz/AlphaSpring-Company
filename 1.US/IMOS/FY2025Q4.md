# ChipMOS Technologies Inc.（IMOS），季报时间：2026-02-24（对应 4Q25 / FY2025；补充到 2026Q1 营收快报）

## 一、财报简评

这季 IMOS 的基调可以概括成一句话：**quarterly beat 很明显，但 full-year 还谈不上漂亮 turnaround**。4Q25 收入 NT$6.52bn，QoQ +6.1%、YoY +20.8%；毛利率 14.3%，环比提升 190bps；EPS/ADS US$0.46，高于公开可见一致预期 US$0.34。驱动核心来自 **memory 尤其 AI / datacenter 相关高价值封测需求**，明显盖过了 DDIC 终端偏弱的拖累。市场层面，财报后公司技术面和情绪都有所改善，外部跟踪媒体提到 IMOS 在财报后技术评分明显抬升。([证券交易委员会](https://www.sec.gov/Archives/edgar/data/1123134/000119312526065089/imos-ex99_1.htm "EX-99.1"))

但如果把镜头拉到全年，2025 其实是**“收入修复、利润被非经营项拖累”**：全年收入同比 +5.5%，但全年净利润只有 NT$495m，同比 -65.1%，主要被外汇损失、联营损失和 2024 年一次性处置收益高基数拖累。也就是说，**季度景气在变好，全年报表质量还没完全跟上**。

## 二、公司信息

ChipMOS 是台湾特色 OSAT 厂，核心逻辑不是跟 ASE/Amkor 拼最宽泛的先进封装平台，而是深耕 **memory、DDIC、gold bump / bumping、mixed-signal** 等细分封测场景，客户覆盖 fabless、IDM 和 foundry。公司 4Q25 收入结构里，**memory 占 49.9%**，**DDIC+gold bump 占 40.2%**；制造别看，**assembly 约 31%**、**testing（mixed-signal+memory test）约 24%**、**wafer bumping 约 22%**。终端市场上，**smartphone 32%**、**auto/industrial 约 27%**、**consumer 约 21%**、**TV panel 超过 12%**、**computing 7.5%**。([ChipMOS TECHNOLOGIES INC.](https://chipmostechnologiesinc.gcs-web.com/static-files/0b09b826-c72c-4ba8-a5b3-df33507cdaa8 "Microsoft Word - 4Q25 Transcript-final.doc"))

这季最值得标红的不是“AI 概念”本身，而是 **AI 带动 memory test / assembly 实际稼动率和 pricing power 回升**。管理层明确说 DRAM 需求持续回暖，DDR4/DDR5 投产拉动明显；同时公司在 2026 年继续推进 memory OSAT 提价，并把 2026 CapEx/sales 提高到 **22%-27%**，其中约 **50% 投向 memory test**，还有一部分投向 flip-chip / RDL，以承接 edge-AI 相关机会。([ChipMOS TECHNOLOGIES INC.](https://chipmostechnologiesinc.gcs-web.com/static-files/0b09b826-c72c-4ba8-a5b3-df33507cdaa8 "Microsoft Word - 4Q25 Transcript-final.doc"))

## 六、增长与资本分配

这轮增长驱动力非常清楚：**不是全面复苏，而是 memory 单腿更强、DDIC 仍偏弱的结构性复苏。** 4Q25 memory 收入占比 49.9%，同比 +55.3%；其中 DRAM 占总收入约 20%，Q/Q 明显增长，Flash 占总收入约 29%。相反，DDIC+gold bump 虽然环比小升，但同比仍下滑。([ChipMOS TECHNOLOGIES INC.](https://chipmostechnologiesinc.gcs-web.com/static-files/0b09b826-c72c-4ba8-a5b3-df33507cdaa8 "Microsoft Word - 4Q25 Transcript-final.doc"))

毛利率改善主要来自 **product mix 更好 + assembly utilization 提升 + pricing discipline**。但这种 margin 改善能否持续，要看两个变量：一是 memory 紧张是否延续到下半年；二是新增折旧能否被产能利用率和提价消化。现在看，天气确实从“阴天”转成“多云转晴”，但还没到“大晴天”。([ChipMOS TECHNOLOGIES INC.](https://chipmostechnologiesinc.gcs-web.com/static-files/0b09b826-c72c-4ba8-a5b3-df33507cdaa8 "Microsoft Word - 4Q25 Transcript-final.doc"))

CapEx 方面，FY25 为 NT$3.67bn，4Q25 单季 NT$1.71bn；4Q25 结构上 testing 占 **55.2%**，assembly **20.6%**，LCD driver **16.5%**，bumping **7.7%**。如果把它拆成维持性和扩展性，我的判断是：**testing、flip-chip / RDL、memory bottleneck 扩产**更偏扩展性，自动化和部分 assembly 投入更偏维持性与效率提升。

## 七、展望与风险

### 7.1 展望

**短期（1年内）**：Q1 季节性放缓已被管理层提前打预防针，但 2026Q1 营收快报仍达 NT$6.94bn，QoQ +6.4%、YoY +25.4%，说明 memory 动能比电话会口径还强一些。([StreetInsider.com](https://www.streetinsider.com/SEC%2BFilings/Form%2B6-K%2BCHIPMOS%2BTECHNOLOGIES%2BFor%3A%2BApr%2B10/26297522.html "Form  6-K        CHIPMOS TECHNOLOGIES      For: Apr 10"))

**中期（1-3年）**：核心看点是 IMOS 能否把自己从“memory 周期受益者”升级成“memory test / assembly 的稀缺产能平台”。若 take-or-pay 合同、memory 提价、flip-chip / RDL 项目逐步兑现，利润率中枢有机会抬升。([ChipMOS TECHNOLOGIES INC.](https://chipmostechnologiesinc.gcs-web.com/static-files/0b09b826-c72c-4ba8-a5b3-df33507cdaa8 "Microsoft Word - 4Q25 Transcript-final.doc"))

**长期（3年以上）**：公司真正的上限不在传统 DDIC，而在 **高价值 memory、mixed-signal diversification、edge-AI 相关封装测试需求**。但它不是 ASE 那种 broad-based 龙头，成长上限更依赖细分赛道景气和客户集中度管理。([ChipMOS TECHNOLOGIES INC.](https://chipmostechnologiesinc.gcs-web.com/static-files/0b09b826-c72c-4ba8-a5b3-df33507cdaa8 "Microsoft Word - 4Q25 Transcript-final.doc"))

### 7.2 风险

正式文件里管理层反复提示的风险包括：**宏观需求波动、通胀与原材料价格、汇率、利率、贸易政策/潜在关税、终端消费疲软，以及客户需求预测误差导致的资本开支错配。** ([证券交易委员会](https://www.sec.gov/Archives/edgar/data/1123134/000119312526065089/imos-ex99_1.htm "EX-99.1"))

### 7.3 市场老问题

老问题还是那几个：**DDIC 需求何时真正回暖、memory 景气能否持续、金价等材料上涨能否顺利传导、CapEx 会不会重新失控。** 最近的改善点在于 memory 和 pricing；未明显改善的是 DDIC，管理层也承认 consumer end-demand softness 仍是行业性问题。

### 9.4 估值（Valuation）
